Projects

Five projects, measured results

LLM Agent with Tool Use

EVGridCopilot

Problem
How many EV chargers can a medium-voltage grid node host? An LLM answering on its own got every test question wrong.
Solution
An AI agent that calls a pandapower power-flow tool to calculate the answer instead of guessing it.
Result
On 10 test questions: LLM alone 0/10 correct → agent with the tool 10/10.
  • Python
  • Claude (Anthropic) API
  • Tool use / function calling
  • pandapower

Solar Power Forecasting

pv-forecast

Problem
Forecast the hourly output of a real 500 kW solar park from weather data.
Solution
A Random Forest model, with the daily forecast automated in n8n and sent via Telegram.
Result
R² 0.94 on days the model had not seen.
  • Python
  • pandas
  • scikit-learn
  • n8n
  • Telegram

Battery Storage Simulation

bess-agent

Problem
Under curtailment, a 500 kW solar park loses energy it could have produced.
Solution
Full-year simulation of a 1,000 kWh battery next to the park, with a pvlib model validated on real data.
Result
The best charging strategy saves 2.4× more energy.
  • Python
  • pvlib
  • scikit-learn
  • SciPy (linear programming)

Solar Monitoring Tool

Voltgaia.gr LIVE BETA

Problem
Knowing how much output a solar park is losing, and why.
Solution
Compares measured output with an independent irradiance model and attributes each loss: grid, maintenance (O&M), panel soiling.
Result
Every loss is priced in euros.

Built in 3 days with prompt, loop and graph engineering.

  • Python
  • JavaScript
  • Huawei FusionSolar API
  • Weather data
